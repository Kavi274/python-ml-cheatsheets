# Contributing

Contributions make this resource better for everyone. All levels welcome.

## How to Contribute

1. Fork the repo
2. Create a branch: `git checkout -b add/your-topic`
3. Make your changes
4. Submit a pull request

## What to Contribute

- Fix a typo or incorrect code snippet
- Add a missing function or technique to an existing cheat sheet
- Add a new cheat sheet (see below for topics we'd love)
- Improve an explanation

## Cheat Sheets We'd Love

- PyTorch
- XGBoost / LightGBM / CatBoost
- SQL for Data Science
- Regex for data cleaning
- Time Series (statsmodels, Prophet)
- NLP (spaCy, NLTK, HuggingFace)
- MLflow / experiment tracking
- Docker for ML

## Code Style

- All code should be copy-pasteable and runnable
- Use descriptive variable names
- Add a comment only when the "why" isn't obvious
- Keep examples short — one concept per snippet

## Cheat Sheet Format

Use this structure for a new cheat sheet:

```markdown
# Topic Name Cheat Sheet

> One-line description.

---

## Imports
\`\`\`python
import ...
\`\`\`

---

## Section Name
\`\`\`python
# code
\`\`\`
```
